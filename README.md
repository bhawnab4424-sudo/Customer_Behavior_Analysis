# Customer Shopping Behaviour Analysis

An end-to-end Data Analytics project using Python, SQL, and Power BI to analyze customer purchasing patterns, spending behaviour, product preferences, discount usage, and subscription trends.

## 1. Project Overview

This project focuses on understanding customer shopping behaviour through data analysis. It follows an end-to-end analytics workflow, starting with data loading and exploratory data analysis in Python, followed by data cleaning, SQL-based business analysis, and Power BI dashboard development.

The objective is to extract meaningful insights from customer shopping data and support data-driven business decisions.

## 2. Project Objectives

- Analyze customer purchasing patterns and preferences.
- Understand spending behaviour across different customer segments.
- Evaluate the impact of discounts and subscriptions on purchasing behaviour.
- Identify popular products and product categories.
- Analyze customer purchase frequency and previous purchase history.
- Visualize business insights using Power BI.

## 3. Dataset Description

- Dataset: Customer Shopping Behaviour
- Total Records: 3,900

## 5. Project Workflow

### Phase 1: Data Loading and Exploration (Python)

- Imported the dataset using Pandas.
- Examined the dataset using head().
- Checked dataset structure using info().
- Generated descriptive statistics using describe().
- Identified missing values using isnull().sum().

### Phase 2: Data Cleaning and Feature Engineering

- Handled missing values in the Review Rating column using category-wise median imputation.
- Standardized column names into lowercase and replaced spaces with underscores.
- Renamed purchase_amount_(usd) to purchase_amount.
- Created an age_group column using quartile-based segmentation with pd.qcut().
- Created a purchase_frequency_days column by mapping purchase frequencies into numerical day intervals.
- Compared Discount Applied and Promo Code Used columns.
- Removed the redundant promo_code_used column.
- Exported the cleaned dataset into a CSV file.

### Phase 3: SQL Business Analysis (MySQL)

Created a database named customer_behaviour and performed SQL analysis to answer 10 business questions.

Business Questions:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used discounts but still spent more than the average purchase amount?
3. Which are the top 5 products with the highest average review rating?
4. How do average purchase amounts compare between Standard and Express Shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest percentage of purchases with discounts applied?
7. How can customers be segmented into New, Returning, and Loyal categories based on previous purchases?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers (more than 5 previous purchases) also likely to subscribe?
10. What is the revenue contribution of each age group?

SQL Concepts Used:

- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregate Functions (SUM, AVG, COUNT)
- Subqueries
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER)
- LIMIT

### Phase 4: Power BI Dashboard

Developed an interactive Power BI dashboard to visualize customer shopping behaviour and communicate business insights.

Dashboard File: Customer_behaviour_analysis dashboard.pbix
